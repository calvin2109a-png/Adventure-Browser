# Changelog

## [1.1.0] - 2026-08-04

### Added
- Embedded `about:home` directly into `index.html` as an internal template.
- New Settings UI with theme (light/dark), background variants, and default search engine selection.

### Changed
- Internal navigation: searches and links now load in the current tab instead of opening new windows.
- Tabs can host internal pages (like `about:home`) and be navigated to web content.
- UI polish and CSS variables for light/dark themes.

### Fixed
- Default search engine is now respected for address bar searches.
